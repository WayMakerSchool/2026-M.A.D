ShoMate 설정 — AI 연결

Gemini 키와 네이버 키는 이 브라우저에만 저장되고 각각 Google·네이버 API 호출에만 사용됩니다. 백엔드 토큰은 아래에 직접 지정한 백엔드 서버에만 전송됩니다.

Gemini API 키

Google AI Studio에서 직접 발급받은 API 키. 백엔드 서버가 없거나 연결되지 않을 때 이 키로 Gemini를 직접 호출합니다.

백엔드 서버 (선택)

ShoMate 백엔드(FastAPI)를 직접 띄운 경우 그 주소. 개발 시에는 http://localhost:8000. 비워두면 백엔드를 사용하지 않습니다(배포판에 기본 서버가 내장된 경우 그 서버를 사용).

서버에 SHOMATE_API_TOKEN 이 설정되어 있을 때만 필요합니다.

네이버 쇼핑 검색 API (선택)

Naver Developers에서 발급한 애플리케이션 키. 네이버 쇼핑 가격 비교(낮은 가격순 검색)에 사용됩니다.
